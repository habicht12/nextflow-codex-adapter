Native Codex runner for Nextflow 26.10.0 and 26.10.2, using a personal ChatGPT
Codex login. Includes declared module tools, structured outputs, filesystem tools,
skills, resume and optional sandboxed shell execution.

Install from a clone with `bin/install`, authenticate with `bin/login`, and run
`nextflow run examples/qc`. See README.md for requirements and
docs/compatibility.md for the tested scope and preview-interface limits.

The plugin ZIP and release metadata are attached. The Linux amd64 runtime is
`ghcr.io/habicht12/nf-agent-codex:0.1.0`.
